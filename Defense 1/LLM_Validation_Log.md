## How verification was done

Nothing below was accepted because it looked right. Three independent checks were used:

1. **Recomputation from the source file.** The FFIEC FR Y-9C bulk file (`data/BHCF20260630.ZIP`, quarter ending 2026-06-30) was parsed separately in Python, outside Power BI, and every metric and every stress path was recalculated from the raw MDRM fields. Output saved as `Defense 1/stress_paths_Q0_Q9.csv` (150 rows: 5 banks x 3 scenarios x 10 quarters).
2. **Cross-check against regulator reported values.** Computed Tier 1 ratios were compared against BHCA7206, the Tier 1 ratio each holding company reports on Schedule HC-R, and against the banks' published quarterly disclosures.
3. **Model level data quality checks.** Row count, distinct RSSD count and a name mismatch count are measures on the Bank Detail page, so the checks run on every refresh rather than once.

A final comparison was run on 2026-09-29: a DAX query returned Q0 and Q9 Tier 1, Q9 liquidity gap, Q9 securities loss as a share of Tier 1, Q9 runoff dollars and total securities for all 5 banks under all 3 scenarios. All 15 rows matched the Python recomputation exactly at 2 decimal places.
