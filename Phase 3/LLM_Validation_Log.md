## How verification was done

Rows P1-P11 preserve the pipeline owner's implementation and verification history. P12-P16 also record the label correction, Codex-assisted checks and final documentation work. A reported pipeline test, an automated recomputation and a human spot check are distinct types of evidence. The checks include:

1. **Reconciliation to the source of record.** Every quarter's row count by form type (031 / 041 / 051) is compared with the CDR Panel of Reporters file that ships inside the same bulk ZIP. Output: `data/phase3/reconciliation.csv`.
2. **Cross check against values the banks report themselves.** Computed or coalesced values were compared with the ratios each bank files (for example Tier 1 leverage, RCFA/RCOA 7204).
3. **Mathematical identity checks.** SHAP values were tested for local accuracy (base value plus contributions must equal the model's log odds for every bank).
4. **Development evaluation after the training period.** Evaluation metrics use 2023-2024 observations not used for model fitting, but reused for comparing variants and selecting the cutoff. The 2026 Q2 figures are current scoring outputs, not matured performance estimates.

The "Human spot check" column records what Loki personally reviewed during the guided checks. "Not individually spot-checked" means no separate human check is claimed for that item; automated or pipeline-owner checks remain described in the preceding columns.
