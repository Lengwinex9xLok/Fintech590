## How verification was done

Nothing below was accepted because it looked right. Four kinds of checks were used:

1. **Reconciliation to the source of record.** Every quarter's row count by form type (031 / 041 / 051) is compared with the CDR Panel of Reporters file that ships inside the same bulk ZIP. Output: `data/phase3/reconciliation.csv`.
2. **Cross check against values the banks report themselves.** Computed or coalesced values were compared with the ratios each bank files (for example Tier 1 leverage, RCFA/RCOA 7204).
3. **Mathematical identity checks.** SHAP values were tested for local accuracy (base value plus contributions must equal the model's log odds for every bank).
4. **Out of time testing.** Every model number in this log comes from 2023 to 2024 data the model never saw in training.

The column "Human spot check" is for the team member who did not build the pipeline. It is blank until that review is done.
